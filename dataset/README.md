# Location1 dataset

`Location1.csv` is the public Location1 benchmark used for training. It contains
43,800 hourly rows and the 36 aligned features used by the code.

`winf_fam1.csv` is **not** included. It is a proprietary 50 MW wind farm
provided by China Huaneng Group. Place a copy at `dataset/winf_fam1.csv` only if
you have a data-use agreement; the file is git-ignored.

See `DATA_LICENSE.md`.
